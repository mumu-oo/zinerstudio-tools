# 誌造所 LINE 客服 — 孔版AI助手 🤖

LINE 官方帳號的自動客服,**穆穆上班時完全靜默、下班時接手回覆**,而且只用穆穆寫過的資料回答,不亂講話。

2025 年 Make + GPT 版的重生。當年的知識庫、人設文案、真實客問都沿用(在 `data/source/`),
但這次守規矩靠的是程式架構,不是拜託 AI。

## 運作方式

```
客人傳 LINE 訊息
   │
   ▼
穆穆值班中?──是──▶ AI助手完全靜默(妳在後台照常手動回)
   │否
   ▼
這間被接手/已轉人工?──是──▶ 靜默
   │否
   ▼
範圍外業務(貼紙/盒子…)?──是──▶ 罐頭婉拒(不花錢)
   │否
   ▼
超過每日額度/爆量熔斷?──是──▶ 罐頭留言(不花錢)
   │否
   ▼
知識庫查得到相關資料?──否──▶ 轉人工留言+該房靜音+通知 Discord(不花錢)
   │是
   ▼
AI 只根據查到的條目回答;沒把握 → 一樣轉人工
```

**防幻覺三道鎖:**
1. 查無資料 → 根本不呼叫 AI
2. AI 的 system prompt 只給查到的條目,鐵則禁止自行推算價格與天數
3. AI 自認沒把握 → 只能輸出轉人工暗號,由程式接手罐頭留言

## 穆穆的遙控器(用妳自己的 LINE 傳給官方帳號)

第一次先傳:`認主 <通關密語>`(密語部署時設定)

| 指令 | 效果 |
|---|---|
| `測試 你的問題` | 用客人視角試AI助手(不受模式影響,狀態隔離在模擬房) |
| `上工` | AI助手接手回覆客人 |
| `收工` | AI助手完全靜默,穆穆親自回 |
| `交給排程` | 平日 10:00–19:00 自動收工、其餘時間自動上工 |
| `狀態` | 看目前模式與今日 AI 用量 |
| `接手 #代號` | 那間聊天室穆穆自己回(代號在 Discord 通知裡) |
| `放行 #代號` | 解除該聊天室靜音 |

指令主詞一律是AI助手。舊詞「上班/下班」因語意模糊(是誰上班?)已退休,傳了只會得到教學訊息,不會改動任何設定。每一則AI助手回覆都掛開頭問候與結尾說明,客人永遠分得出這不是 MUMU 本人。

## 成本與安全上限(都在 `src/config.js` 可調)

- 每位客人每天最多 20 次 AI 回覆(穆穆的「測試」不佔額度);全帳號每天上限 100 次 → **最壞情況的日成本是封頂的**
- 10 分鐘超過 30 則訊息自動熔斷,只回罐頭 + Discord 警報
- 只用 LINE 的「回覆」不用「推播」→ 不占官方帳號訊息額度
- 模型可插拔(OpenAI 相容端點或 Anthropic),`wrangler.toml` 改兩行就換

## 更新知識庫

改 `data/source/孔版客服QA - 工作表1.csv`(或直接跟 Claude 說),然後:

```
npm run kb      # CSV → data/kb.json
npm test        # 44 條測試,含真實客問檢索驗證
npm run deploy
```

## 還沒接上線,差三把鑰匙

1. **LINE**:官方帳號後台啟用 Messaging API → 拿 Channel secret + access token
2. **Cloudflare**:免費帳號(程式住這裡,不用養主機)
3. **AI 模型**:OpenAI API key(或其他;客人訊息含個資,不建議接境外疑慮服務)

鑰匙到手後的部署步驟寫在 `wrangler.toml` 開頭註解,由 Claude 操作即可。
